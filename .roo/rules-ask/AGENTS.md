# AGENTS.md

Этот файл фиксирует только проектно-специфичные и неочевидные правила для режима `ask`.

- Документация в `rules/` и `tests/` может быть устаревшей, актуальными считаются примеры в коде.  
- Файлы [`tests/additional_test_cases.md`](tests/additional_test_cases.md) и [`tests/tests_audit.md`](tests/tests_audit.md) содержат важные edge cases.  
- Основным источником по тестированию RAG является [`tests/rag/TESTING_STRATEGY.md`](tests/rag/TESTING_STRATEGY.md).
