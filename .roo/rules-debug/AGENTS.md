# AGENTS.md

Этот файл фиксирует только проектно-специфичные и неочевидные правила для режима `debug`.

- Все отладочные сценарии должны выполняться в offline/mock режиме.  
- VM-тесты требуют наличия `VM_PASSWORD` и доступа по SSH.  
- Проверка окружения выполняется через [`scripts/validate_vm_env.py`](scripts/validate_vm_env.py).  
- При необходимости должна выполняться автоматическая миграция Qdrant коллекций.
