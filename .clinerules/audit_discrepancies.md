### 2. Async/Sync проблемы: Устаревшая информация

**Проблема:** Документация описывает async проблемы как критические, но код уже содержит решения.

**Документация (activeContext.md):**
```python
# ПРОБЛЕМА:
async def embed_texts() -> np.ndarray  # Возвращает coroutine

# РЕШЕНИЕ:
def embed_texts() -> np.ndarray        # Синхронный wrapper с asyncio.run()
```

**Реальное состояние кода (remote_embedder.py):**
```python
def embed_texts(self, texts: List[str], task: str = None) -> np.ndarray:
    """Синхронная обёртка над запросом embeddings к VM"""
    return run_async_safe(
        self._async_embed_texts(texts, task=task, deadline_ms=deadline_ms),
        timeout=deadline_seconds
    )
```

**Расхождение:** Документация показывает планируемое решение, код уже содержит реализацию.

## ⚙️ ТЕХНИЧЕСКИЕ НЕСООТВЕТСТВИЯ

### 1. Vector Dimensions: Конфликт размерностей

**Проблема:** Несоответствие размерностей векторов между документацией и кодом.

**Документация (techContext.md):**
```markdown
- **Adaptive HNSW**: динамические параметры (m=16, ef_construct=200 для 1024d)
- **Matryoshka Compression**: 1024d → 384d сжатие для эффективности
```

**Конфигурация (settings.json):**
```json
{
  "embeddings": {
    "truncate_dim": 768,
    "model_name": "jinaai/jina-embeddings-v3"
  },
  "vector_store": {
    "vector_size": 1024
  }
}
```

**Расхождение:** 
- Документация упоминает 384d как целевую размерность
- Код использует 768d как truncate_dim
- Vector store настроен на 1024d (исходная размерность Jina v3)

**Влияние:** Несогласованность может привести к ошибкам при индексации и поиске.

### 2. Health Check методы: Несоответствия в описаниях

**Проблема:** Разные описания health check методов в документации и коде.

**Документация (techContext.md):**
```python
def health_check(self) -> dict:
    return {
        "status": "healthy",
        "components": {
            "vector_store": self._check_vector_store(),
            "embedder": self._check_embedder(),
            "openai_api": self._check_openai_api()
        }
    }
```

**Реальный код (remote_embedder.py):**
```python
async def health_check(self) -> Dict[str, Any]:
    health_info = {
        'status': 'unknown',
        'service_url': self.embeddings_endpoint,
        'provider': self.provider_name,
        'model_name': self.model_name,
        'embedding_dim': self.embedding_dim,
        'truncate_dim': self.truncate_dim,
        'error': None
    }
```

**Расхождение:** 
- Документация описывает синхронный метод с проверкой компонентов
- Код содержит асинхронный метод с проверкой удаленного сервиса
- Разные структуры возвращаемых данных
