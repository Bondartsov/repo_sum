## 🚨 Критические проблемы (блокирующие функциональность)

### **1. Async/Sync проблемы в remote клиентах**
**Статус:** ❌ КРИТИЧЕСКИЙ (блокирует весь RAG функционал)
**Влияние:** RuntimeWarning, `object of type 'coroutine' has no len()` ошибки
**Файлы:** `rag/remote_embedder.py`, `rag/remote_vector_store.py`, `rag/search_service.py`

**Проблема:**
```python
# В remote_embedder.py:
async def embed_texts() -> np.ndarray  # Возвращает coroutine

# В search_service.py:
embeddings = self.embedder.embed_texts(texts)  # Синхронный вызов
# Результат: RuntimeWarning: coroutine was never awaited
```

**Решение:**
```python
def embed_texts(self, texts: List[str], task: str = None) -> np.ndarray:
    """Синхронный wrapper для async HTTP запроса"""
    return run_async_safe(
        self._async_embed_texts(texts, task=task),
        timeout=30
    )
```

**Оценка:** 1-2 дня, сложность: высокая
**Приоритет:** P0 (блокирует M2.5 completion)

### **2. Несоответствие статуса M2.5 между документацией и кодом**
**Статус:** ❌ КРИТИЧЕСКИЙ (создает ложное впечатление о проблемах)
**Влияние:** Пользователи думают что async проблемы не решены
**Файлы:** `rules/activeContext.md`, `rules/progress.md`, `rules/project_status.md`

**Проблема:**
- Документация показывает M2.5 как 80% с критическими async проблемами

**Решение:** Обновить статус во всех файлах на 95% с указанием что async исправления реализованы

**Оценка:** 0.5 дня, сложность: низкая
**Приоритет:** P0 (влияет на perception проекта)

### **3. Несоответствие размерностей векторов**
**Статус:** ❌ КРИТИЧЕСКИЙ (приводит к ошибкам индексации)
**Влияние:** Несогласованность может привести к ошибкам при индексации и поиске
**Файлы:** `settings.json`, `rules/techContext.md`

**Проблема:**
- Документация упоминает 384d как целевую размерность
- Код использует 768d как truncate_dim
- Vector store настроен на 1024d

**Решение:**
```json
{
  "embeddings": {
    "truncate_dim": 1024,
    "embedding_dim": 1024
  },
  "vector_store": {
    "vector_size": 1024
  }
}
```

**Оценка:** 0.5 дня, сложность: средняя
**Приоритет:** P0 (влияет на качество поиска)

### **4. Разные описания health check методов**
