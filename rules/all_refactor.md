# Приложение A. Контракт API и DTO-схемы

**Версия контракта:** `api_contract: v1.0.0`

## A.1. Общие требования
- Заголовки: `X-API-Contract: v1.0.0`, `X-Embedding-Version: <строка>`, `X-Batch-Id: <uuid>` для `/index`.
- Тип контента: `application/json; charset=utf-8`. Кодировка: UTF-8.
- Ошибки: при нарушении схем — **422** с деталями; для перегрузки — **503**.

## A.2. `IndexedDocument`
**Обязательные поля:** `id`, `text`, `metadata`, `embedding_version`, `content_sha256`.  
**Метаданные минимум:** `file_path`, `line_start`, `line_end`, `language`, `repo`, `chunk_type`.

**JSON Schema (фрагмент):**
```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "title": "IndexedDocument",
  "type": "object",
  "required": ["id", "text", "metadata", "embedding_version", "content_sha256"],
  "properties": {
    "id": { "type": "string", "minLength": 1 },
    "text": { "type": "string", "minLength": 1 },
    "metadata": {
      "type": "object",
      "required": ["file_path", "line_start", "line_end", "language", "repo", "chunk_type"]
    },
    "embedding_version": { "type": "string", "minLength": 1 },
    "content_sha256": {
      "type": "string",
      "pattern": "^[A-Fa-f0-9]{64}$"
    }
  }
}
```

## A.3. `/index` (batch indexing)
**Request:**
```json
{
  "api_contract": "v1.0.0",
  "batch_id": "c0d8b4f2-1a8d-4e8f-9d7e-2c1a5b8d9f01",
  "documents": [ { /* IndexedDocument */ } ]
}
```
Ограничения: `1..128` документов; budget по токенам/байтам; `text` не пустой; корректный `content_sha256`.

**Response (успех):**
```json
{ "accepted": 126, "rejected": 2, "rejected_reasons": [ { "id": "src/a.py#10-12", "reason": "empty_text" } ], "elapsed_ms": 1534 }
```

**Ошибки:** `400` (контракт/формат), `422` (валидация), `503` (breaker/перегрузка).

## A.4. `/search`
**SearchRequest (фрагмент):**
```json
{
  "api_contract": "v1.0.0",
  "query": "Как строится пайплайн индексации?",
  "top_k": 10,
  "filters": { "repo": "repo_sum", "language": ["python", "md"] },
  "embedding_version": "2025-10-A"
}
```
**SearchResponse (фрагмент):**
```json
{
  "results": [ { "id": "src/rag/indexer.py#50-98", "score": 0.8421, "metadata": { "file_path": "src/rag/indexer.py" } } ],
  "elapsed_ms": 214
}
```
Ошибки: `400` (недопустимые параметры), `422` (пустой `query`), `503` (breaker/перегрузка).

## A.5. Единый формат ошибок
```json
{
  "error": {
    "type": "validation_error",
    "message": "text must be non-empty",
    "details": [ { "id": "src/a.py#10-12", "field": "text", "issue": "empty" } ],
    "request_id": "6c6c3b06-77c4-4518-8a6e-8120a9bb1a23",
    "api_contract": "v1.0.0"
  }
}
```
