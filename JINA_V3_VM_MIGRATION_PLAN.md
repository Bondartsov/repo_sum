# 🚀 План миграции Jina v3 на VM: RAG-as-a-Service

**Дата создания:** 15 сентября 2025  
**Цель:** Развертывание jinaai/jina-embeddings-v3 на t-ubuntu-redis (32GB RAM)  
**Архитектура:** RAG-as-a-Service с удаленным доступом

---

## 🎯 Обоснование миграции

### ❌ Текущие проблемы локально:
- HuggingFace не может загрузить кастомные модули Jina v3 (`trust_remote_code=True` не работает)
- FastEmbed + ONNX требует 25+ GB RAM для attention операций Jina v3
- Локальная память недостаточна для стабильной работы (16GB vs требуемые 32GB+)
- Система fallback на FastEmbed, но качество поиска остается низким

### ✅ Решение VM:
- **32GB RAM** - достаточно для sentence-transformers + Jina v3 (570M параметров)
- **Стабильная работа** без OOM ошибок
- **Централизованное развертывание** - Qdrant + RAG на одной машине
- **Лучшая производительность** - большие batch sizes, полные 1024d векторы

---

## 🏗️ Целевая архитектура: RAG-as-a-Service

```
[Локальная машина]                    [VM t-ubuntu-redis 10.61.11.54]
├─ repo_sum CLI                   ←→  ├─ FastAPI RAG Service (port 8000)
├─ Web UI (Streamlit)            HTTP ├─ jinaai/jina-embeddings-v3
├─ Анализ кода                        ├─ sentence-transformers>=3.0
└─ OpenAI документирование            └─ Qdrant (port 6333) - уже работает

Взаимодействие: HTTP REST API для индексации и поиска
```

## 🔧 Технические спецификации

### VM Характеристики:
- **Host:** t-ubuntu-redis (10.61.11.54)
- **CPU:** Xeon Gold 6248R, 4 ядра
- **RAM:** 32 GB (в 2 раза больше локальной)
- **Disk:** 100 GB
- **OS:** Ubuntu (предположительно)

### Программный стек:
- **Python:** 3.9+
- **FastAPI:** для REST API
- **sentence-transformers:** >=3.0 для Jina v3
- **jinaai/jina-embeddings-v3:** основная модель (570M параметров)
- **Qdrant:** существующий instance на 6333
- **nginx:** reverse proxy (опционально)

### Конфигурация Jina v3:
```json
{
  "embeddings": {
    "provider": "sentence-transformers",
    "model_name": "jinaai/jina-embeddings-v3", 
    "truncate_dim": 1024,
    "batch_size_max": 128,
    "trust_remote_code": true,
    "task_query": "retrieval.query",
    "task_passage": "retrieval.passage"
  }
}
```
